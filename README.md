# Expense Tracker

A simple front-end expense tracker app for tracking income, expenses, and recent transactions.

## Features

- Monthly income and expense summary cards
- Overview chart for spending trends
- Expense breakdown by category
- Recent transaction list
- Add income and expense entries from modal forms
- Responsive design for browser use

## Files

- `index.html` – page structure
- `style.css` – styling
- `script.js` – interaction logic

## How to run

You can open the app directly in a browser:

1. Open `index.html` in your browser, or
2. Start a local web server from the project folder:

Windows PowerShell:

```powershell
py -m http.server 8000
```

macOS/Linux:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

This project uses plain HTML, CSS, and JavaScript, so no installation or build step is required.
